# BARFEAND

Web oficial de BARFEAND, marca d’alimentació BARF d’El Rebost del Nord.

- Idioma principal: català.
- Web estàtica: HTML, CSS i JavaScript.
- Publicació: GitHub Pages des de la branca `main` mitjançant GitHub Actions.
- Domini: `barfeand.com`.
- Catàleg: Pollastre, Gall d’indi, Vedella d’Andorra, Xai, Porc Duroc, Conill i Multiproteïna.
- Formats: 1 kg i 500 g, excepte Conill, disponible només en 500 g.
